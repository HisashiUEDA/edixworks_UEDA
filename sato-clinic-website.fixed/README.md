# 佐藤医院 静的Webサイト

参考デザインのページ構成と提供写真・掲載原稿に基づいた、PC向けのHTML/CSSサイトです。

## 開き方

ZIPファイルを解凍し、`index.html` をブラウザで開いてください。特別な開発環境やビルド操作は必要ありません。

## ファイル構成

- `index.html` — トップページ（診療時間・お知らせ・院長挨拶・診療内容・当院紹介・スタッフ・アクセス・FAQ）
- `news.html` — お知らせ詳細
- `medical.html` — 診療内容の追加項目
- `about.html` — 当院について詳細
- `faq.html` — その他のご質問
- `hours-access.html` — 診療時間・所在地の詳細
- `css/style.css` — 共通スタイル
- `images/` — 提供された画像素材（Web表示向けに最適化）

## 仕様

- 日本語・UTF-8
- HTML/CSSのみ（JavaScript、フレームワーク不使用）
- Google Fontsから **Noto Sans JP** を読み込み（ネット接続がない場合は日本語の代替フォントで表示）
- 参考画像に合わせたPC向け固定レイアウト（レスポンシブ対応は未実施）
- リンクは同梱ページ・ページ内セクションに接続

**ご注意：** 医院名・住所・電話番号・メールなどは、提供された教材用の架空情報です。本番運用には内容の確認・差し替えが必要です。
